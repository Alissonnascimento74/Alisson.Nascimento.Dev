# alissonnascimento.dev

Meu portfólio pessoal. Construído com foco em design minimalista, performance e atenção aos detalhes — princípios que tento aplicar também no desenvolvimento iOS.

🔗 **Live:** [seu-portfolio.vercel.app](https://seu-portfolio.vercel.app)

## Stack

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- Hospedado na **Vercel**

## Estrutura

```
app/                    rotas (home, /blog, /projetos/[slug])
components/             componentes da UI
data/content.ts         conteúdo do site (perfil, projetos, posts)
lib/markdown.ts         parser markdown leve
```

## Rodando localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.
